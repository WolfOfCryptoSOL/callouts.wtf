WebSocket API

Receive Pump.fun callouts in your own code the moment we see them. Available from the Builder plan; "every callout" mode from Pro.

1. Get a key

In @Calloutswtfbot: 📬 Deliver To → 🔑 API key. The key is shown once — store it safely. Creating a new key beyond your plan's limit retires your oldest key.

2. Connect

wss://api.callouts.wtf/v1/stream
Authorization: Bearer <your key>

One live connection per key; a new connection with the same key replaces the old one. The server sends a heartbeat ping every 15 seconds.

On connect you receive:

{"type": "welcome", "plan": "pro", "all_callouts": true, "available": true}

3. Subscribe

By default you receive the callers you added in the bot (originals and updates). Send a subscribe message to change what you get:

{"type": "subscribe", "all": false, "kinds": ["original", "update", "repost", "quote"]}
FieldMeaning
alltrue = every Pump.fun callout (Pro and Fast Lane). false = only your callers.
kindsAny of original, update, repost, quote. Reposts and quotes need Builder or higher.

4. Callout events

{
  "type": "callout",
  "source": "pumpfun",
  "kind": "original",
  "callout_id": "8a0be443-e776-4f09-8fe3-d4eabccc60b7",
  "update_index": 0,
  "caller": {"handle": "EustazZ", "user_id": "6d1b989f-…", "wallet": "FqamE7xrah…"},
  "token": {"mint": "DdYmLRMQLtoMqutPCapAHPYsrnVZxgNZB2ZG4eTBpump", "chain": "solana"},
  "linked_callout_id": null,
  "pump_created_at": 1793268320808,
  "sent_at": 1793268320941,
  "fast": true
}
FieldMeaning
kindoriginal, update (the caller's own update on that callout), repost or quote.
update_index0 for the original; 1, 2, … for the caller's updates.
token.chainsolana, base, bsc, ethereum or robinhood.
linked_callout_idFor reposts and quotes: the callout they refer to.
pump_created_atPump.fun's own creation time (ms). sent_at - pump_created_at is our end-to-end time to you.
fasttrue when the callout came through the fast path.

Each callout is sent once. If the service is unavailable you receive {"type": "status", "source": "pumpfun", "available": false}, and true when it is back.

5. Catch-up (Pro and Fast Lane)

Turn on catch-up in the bot (⚙️ Settings), then reconnect with ?since=<ms timestamp> to receive callouts you missed in the last 10 minutes.

Examples

JavaScript (Node 22+):

const ws = new WebSocket("wss://api.callouts.wtf/v1/stream", {headers: {Authorization: "Bearer " + process.env.CALLOUTS_KEY}});
ws.onopen = () => ws.send(JSON.stringify({type: "subscribe", all: false, kinds: ["original"]}));
ws.onmessage = (m) => { const e = JSON.parse(m.data); if (e.type === "callout") console.log(e.caller.handle, e.token.mint); };

Python (pip install websockets):

import asyncio, json, os, websockets

async def main():
    headers = {"Authorization": "Bearer " + os.environ["CALLOUTS_KEY"]}
    async with websockets.connect("wss://api.callouts.wtf/v1/stream", additional_headers=headers) as ws:
        await ws.send(json.dumps({"type": "subscribe", "all": False, "kinds": ["original", "update"]}))
        async for raw in ws:
            e = json.loads(raw)
            if e["type"] == "callout":
                print(e["caller"]["handle"], e["token"]["mint"], e["sent_at"] - e["pump_created_at"], "ms")

asyncio.run(main())
